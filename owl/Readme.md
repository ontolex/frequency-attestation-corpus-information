# FrAC OWL Ontology

`frac.ttl` is **generated** — do not edit it directly. It is extracted from
the RDFa markup in the specification source, [`../index.md`](../index.md).
To regenerate it after changing `index.md`, run

	$> make

in this directory (or `./extract-ontology.sh owl/frac.ttl` from the
repository root). See the [top-level README](../README.md#the-ontology-rdfa)
for the required tools.
